# R.M.P Studio

App de Real Mente Poder para convertir y descargar archivos.

Repo: https://github.com/rmpsorva/RMP-Studio

## Qué incluye
- Video → MP4 / WebM / MOV / GIF / MP3
- Recorte de video o audio por segundos
- Extraer audio de un video
- Imagen → JPG / PNG / WEBP
- Recorte TikTok 9:16, cuadrado, YouTube 16:9
- Rotar 90 / 180 / 270
- Varias imágenes a PDF
- Descargar desde URL
- Empaquetar ZIP y GZIP
- Vault MENTAL STATE

## GitHub Pages
Settings → Pages → Deploy from branch `main` → folder `/`
URL: https://rmpsorva.github.io/RMP-Studio/

Imagen y PDF funcionan en el teléfono. Video/audio necesitan HTTPS (Pages sirve).
